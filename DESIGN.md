# Оформление фестиваля — «Персона Лета»

Стиль экранов фестиваля (`/festival/screen/:slug`, судейский экран). К искрам не
относится: у них своя тёмно-нейтральная тема в `client/src/design-system/`.

## Концепция

Ночная арена шоу. Глубокий синий зал с LED-стеной из точек, фермы и прожекторы
сверху, лучи света и конфетти в воздухе, глянцевый мокрый пол с полосами,
уходящими в точку схода с ярким свечением на горизонте. Всё тёмное и синее,
кроме акцентов, которые светятся. Настроение — телевизионное шоу, не детский
праздник: насыщенно и глянцево, но композиция строгая и симметричная.

## Токены

```css
/* Фон: от почти чёрного к электрику */
--bg-abyss:      #000A2E;
--bg-deep:       #00113F;
--bg-mid:        #001D62;
--bg-arena:      #002480;
--bg-floor-near: #001045;

/* Свет */
--glow-core:     #0962D9;
--glow-beam:     #1789D3;
--glow-horizon:  #3BA4DB;

/* Акценты бренда */
--acc-magenta:   #E40079;
--acc-magenta-2: #D0068A;
--acc-cyan:      #0099D9;
--acc-cyan-2:    #1FB2F1;
--acc-lime:      #72CC25;
--acc-lime-2:    #589B10;
--acc-amber:     #FFB400;
--acc-violet:    #7A2FC4;

/* Текст и поверхности */
--text:          #FFFFFF;
--text-dim:      #A9C4E8;
--surface:       rgba(255,255,255,0.06);
--stroke:        rgba(120,180,255,0.22);
```

Фон страницы:
```css
background:
  radial-gradient(120% 80% at 50% 74%, var(--glow-core) 0%, transparent 55%),
  radial-gradient(90% 70% at 50% 20%, var(--bg-arena) 0%, transparent 60%),
  linear-gradient(180deg, var(--bg-mid) 0%, var(--bg-deep) 55%, var(--bg-abyss) 100%);
```

**Правило акцентов:** акцент никогда не занимает большие площади. Магента, лайм,
циан, янтарь — только кнопки, бейджи, полосы, иконки и подсветка карточек. Фон
всегда синий.

## Типографика

Дисплейный: **Unbounded** 800/900, только капс, `line-height: 0.88`,
`letter-spacing: -0.01em`. Текстовый: **Inter** 400/500/600.

```
h1  clamp(56px, 9vw, 148px)  Unbounded 900, uppercase
h2  clamp(32px, 4.5vw, 64px) Unbounded 800, uppercase
h3  24–32px                  Inter 600
body 16–18px                 Inter 400, --text-dim
label 12–13px                Inter 600, uppercase, letter-spacing 0.14em
```

Объёмные надувные буквы — только картинкой (PNG из макета) со свечением:
```css
filter: drop-shadow(0 0 40px rgba(255,255,255,.45)) drop-shadow(0 0 120px rgba(120,180,255,.35));
```
Фолбэк и остальные заголовки — плоский белый капс:
```css
text-shadow: 0 2px 0 #C8C8C8, 0 6px 24px rgba(0,0,0,.5), 0 0 60px rgba(255,255,255,.35);
```
Изображать объём средствами CSS не пытаемся.

## Разделитель

Фирменный элемент: полоса 6px, скруглённая, 380–480px, по центру. Три сегмента:
лайм 38%, янтарь 26%, лайм 36%. Ставится под каждый h2 и между секциями.

## Слои сцены

Снизу вверх: базовый градиент → LED-стена (точки 1–2px, `--glow-beam`,
opacity 0.25, ячейка 14px, радиальная маска, гаснущая к центру) → лучи
прожекторов (4–6 конусов сверху, opacity 0.12–0.2, blur 40px) → пол (нижние 35%,
`linear-gradient(180deg, var(--bg-arena), var(--bg-floor-near))` плюс две белые
линии в перспективе к точке 50%/72%) → свечение горизонта (белый блик 60px в
точке схода) → конфетти (30–50 прямоугольников 4×8px, магента/циан/белый,
opacity 0.5) → контент.

## Компоненты

- **Кнопка основная:** фон `--acc-magenta`, белый текст, высота 56px,
  padding 0 36px, radius 999px, Inter 600 16px uppercase, `letter-spacing .06em`,
  `box-shadow: 0 0 32px rgba(228,0,121,.5)`. Hover — сдвиг в янтарь, свечение растёт.
- **Кнопка вторичная:** прозрачный фон, border 2px `--acc-cyan`, белый текст.
- **Карточка:** `--surface`, `backdrop-filter: blur(12px)`, border 1px `--stroke`,
  radius 24px, padding 32px; верхняя кромка — полоса 4px, цвет по кругу из четырёх акцентов.
- **Бейдж/номер:** круг 48px, заливка акцентом, цифра `--bg-abyss`, Unbounded 800.

## Движение

Медленное и малозаметное: лучи качаются 12–18 с `ease-in-out infinite alternate`,
конфетти падает 8–14 с с разными задержками, свечение горизонта пульсирует 4 с.
При `prefers-reduced-motion` всё выключается.

## Чего не делать

Не осветлять фон. Не делать белых и светлых секций — страница синяя от начала до
конца. Не заливать блоки акцентом на всю ширину. Не добавлять пятый акцент. Не
ставить тонкие шрифты: минимум 400, у заголовков только 800–900.

## Как это применено на экране показа

`client/src/features/festival/festival-screen.css` — токены объявлены на `.fest`,
чтобы не задевать тему искр. Размеры в `cqw` (кадр 4:3 не прокручивается ни при
каком размере окна). Шрифты подключаются только этим экраном, из `ScreenPage`.

Круг с фишками заменён дорожками: 22 участника на одном рубеже превращали круг в
кашу из номеров. Строка на участника — место, номер-бейдж цветом команды, ФИ,
трек из делений (рубежи + закрытие круга), личный секундомер, штрафы и баллы.
Скопление на рубеже читается по тому, что у нескольких дорожек горит одно и то же
деление.
